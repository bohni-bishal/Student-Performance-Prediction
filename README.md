# Student Performance Prediction

### Machine Learning Project using Python

## 1. Introduction

Student Performance Prediction is a machine learning project that predicts a student's final mathematics grade based on academic and personal study-related information.

The project uses Python and the Linear Regression algorithm to analyse historical student data and estimate academic performance.

## 2. Project Objective

The main objectives are:

- To analyse student academic performance.
- To understand the relationship between study time and grades.
- To predict final mathematics grades using Machine Learning.
- To demonstrate the practical application of Python and data analysis.

## 3. Technologies Used

- Python
- Pandas
- Scikit-learn
- Linear Regression
- PyCharm

## 4. Dataset

The project uses the Student Performance dataset from the UCI Machine Learning Repository.

Dataset: https://archive.ics.uci.edu/dataset/320/student+performance

The dataset contains 649 student records and 30 features.

## 5. Input Features

The model uses the following inputs:

| Feature | Description |
|---|---|
| Study Time | Weekly study-time category (1–4) |
| Failures | Number of past class failures |
| Absences | Number of school absences |
| G1 | First-period mathematics grade |
| G2 | Second-period mathematics grade |

## 6. Machine Learning Algorithm

The project uses Linear Regression.

The dataset is divided into training and testing sets. The model learns from the training data and is evaluated using the testing data.

Mean Absolute Error (MAE) is used to measure prediction error.

## 8. How to Run the Project

1. Install Python.
2. Install the required libraries:

```bash
pip install pandas scikit-learn
```

3. Download or clone this repository.
4. Keep `main.py` and `student-mat.csv` in the same folder.
5. Run the program:

```bash
python main.py
```

6. Enter the requested student details.
